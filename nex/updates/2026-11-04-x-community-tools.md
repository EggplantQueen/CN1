# CN1 — Telegram community tools and X discovery (2026-11-04)

This is a **dated, owner-reported project update**. It describes CN1's own tools and the direction for optional community integrations, without exposing credentials, member data, internal endpoints or unpublished release details. This is **not** a live API health report.

## CN1 Raid Bot — existing Telegram tooling

CN1 has a dedicated Telegram Raid Bot for **optional community missions around selected X posts**. Community administrators can configure mission timing and participation settings; participation and any XP rules belong to the specific approved CN1 system, not to NEX. A member's own voluntary interaction should never be confused with independently verified likes, reposts or replies. Free/manual use does **not** promise automatic verification of all X interactions.

Its purpose is to organize legitimate community activity. It is not permission for forced posting, harassment, mass mentions, coordinated manipulation or copy-paste replies.

## NEX X Radar — owner-controlled Telegram pilot

On November 4, CN1's owner **installed and tested** the X Radar Telegram pilot with NEX (`@CN1Nex_bot`).

NEX can display a selected X conversation in an **owner-approved Telegram preview**. The relevant public post link is shared only after the human owner explicitly approves it; the owner can dismiss it instead. Community members can choose to read or respond naturally, or ignore it altogether. No mass notifications, forced raids, automatic replies, engagement XP or unlimited group alerts are promised.

This function is **distinct from the Raid Bot**. Connecting the two products, with explicit opt-in and safety limits, is only a **future design possibility**, not a live integrated feature.

## Relevant X conversations — curated discovery and future automation

The CN1 team is using a **human-curated X opportunity watch** to identify relevant, recent discussion about Solana, memecoins, GameFi/games, Web3 and Telegram community tools. Suggestions are reviewed by a human before anyone posts. No automated X replies or cross-platform mass-engagement campaigns have been authorized.

An integrated always-on X discovery feed that automatically provides candidate links to NEX is **not deployed**. The current X Radar accepts posts selected by the owner. Broader automation could require approved third-party data access and possibly an X API plan, with rate limits and running costs; it must not be marketed as included or free before those dependencies are confirmed.

## Product availability and customer promises

- CN1 Community OS offers **free non-AI Telegram moderation** with an optional customizable AI assistant; implementation and pricing for other communities depend on the requested setup.
- Raid Bot is an existing CN1 tool. General customer availability and X engagement verification may differ by configuration.
- X Radar is **tested in the owner's own Telegram pilot**, not a generally available turn-key monitoring service.
- Automated discovery, Raid Bot ↔ NEX integration, auto-publishing and X engagement verification are **not presented as shipped**.
- An optional shared community discussion must always be voluntary: no spam, no pressure, no coordinated copy-paste.

See the [CN1 Community OS site](https://eggplantqueen.lol/bot/) for the publicly presented product overview and current access-by-request contact details.
