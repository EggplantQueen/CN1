# CN1 website — public lab update

**As of 3 November 2026 · Status: in development**

The CN1 / The Eggplant Queen website is being redesigned around the actual CN1 universe and its original assets. This is a progress checkpoint, **not** a launch announcement.

## Prepared for review

- A redesigned homepage brings together the existing 3D Club, CN1 games, MUTANT/NEX laboratory, Telegram Community OS and the wider project.
- Dedicated presentation pages for the proposed **Community Arcade** and future **CN1 Shop** have been created.
- A consistent navigation and footer connect the main site sections and the official CN1 Club YouTube channel: https://www.youtube.com/@TheCN1Club.
- Real existing Club 3D model media and original MUTANT laboratory art have been selected for the homepage. The updated site still needs proper browser and deployment checks.
- Community OS is described as free Telegram moderation, with an optional personalized assistant and low-cost features depending on the community's needs. No unapproved price or automatic purchase is advertised.

## Not live yet

The redesigned homepage and the new pages are **not published on the public site** as of this checkpoint. Guest game submissions, website/Telegram voting, a shared Shop catalogue, paid checkout, and future holder or Telegram Stars systems are proposals or future implementation work, not available features. A confirmed release date or public preview date has **not** been announced.

For project news, follow the official CN1 channel: https://t.me/CN1EggplantQueen.

*This note covers the public-facing project status only. It does not disclose private configuration, source structure, unpublished media or access details.*
