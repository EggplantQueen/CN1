# CN1 — Public Roadmap

This is not a promise machine.

It is a public view of what CN1 is working on **right now**, what is likely to come next, and what is still sitting in the "maybe this is a terrible idea" pile.

Plans can move. Builds can break. Things get rebuilt.

That is normal here.

---

## NOW

### 3D CN1
Build the reusable 3D version of CN1 that can actually work across the ecosystem.

Targets:
- recognizable CN1 face and identity;
- clean rigging and animation;
- usable in games;
- usable in the CLUB;
- usable for content and marketing;
- usable for future interactive appearances;
- optimized enough that she does not melt everyone's laptop.

### the CLUB
Keep turning the CLUB into a real online CN1 social/music space.

Current direction:
- community presence;
- music and events;
- avatars;
- moderation tools;
- visual identity;
- more reasons to actually come back.

### Lower Rooms
Continue the CN1 combat / multiplayer experiment.

Current focus:
- better movement;
- less stupid path repetition;
- better target acquisition;
- better aiming;
- more convincing CN1 behavior;
- multiplayer systems that survive contact with reality.

### Public CN1
Make the project easier to understand from the outside.

That means:
- clearer GitHub;
- clearer website;
- better screenshots and clips;
- consistent X / Telegram / Reddit presentation;
- actual progress instead of manufactured hype.

---

## NEXT

### Games
Keep improving the parts of the CN1 game ecosystem that deserve to survive.

Possible work includes:
- Eggplant Slots updates;
- new community game loops;
- better XP / progression connections;
- experiments that connect Telegram, games and the wider CN1 universe.

### CN1 everywhere
Use the same character foundation across more surfaces instead of rebuilding her from scratch every time.

Games.  
the CLUB.  
Videos.  
Social content.  
Interactive appearances.

One CN1. More bad environments to put her in.

### Community systems
More useful ways for the community to interact with CN1 and with each other.

No fake "engagement mechanics" just because a dashboard says they are good.

If it is boring, it dies.

---

## LATER

These are directions, **not promises**.

- larger connected multiplayer experiences;
- more rooms / environments / events;
- expanded CN1 character content;
- short-form animated content;
- comics and visual storytelling;
- more ways for CN1 to exist outside a static profile picture;
- experiments we have not had the bad judgment to start yet.

---

## The rule

CN1 does not ship features because a roadmap box exists.

We build it.  
We test it.  
If it is good, it stays.  
If it is bad, it gets fixed or killed.

**That is the roadmap.**
